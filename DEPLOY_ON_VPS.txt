═══════════════════════════════════════════════════════════════
   EXACT COMMANDS TO RUN ON YOUR VPS (corridors)
═══════════════════════════════════════════════════════════════

Copy and paste these commands one by one into your VPS terminal.

-------------------------------------------------------------------
STEP 1: Navigate to Project Directory
-------------------------------------------------------------------

cd ~/InternalDevelopersPlatform

-------------------------------------------------------------------
STEP 2: Pull Latest Changes (if using Git)
-------------------------------------------------------------------

git pull

# Or if you uploaded files manually, skip this step

-------------------------------------------------------------------
STEP 3: Create/Update .env File
-------------------------------------------------------------------

cp .env.example .env

# The default .env works for demo mode, but if you want to customize:
# nano .env
# (Edit if needed, then Ctrl+X, Y, Enter to save)

-------------------------------------------------------------------
STEP 4: Stop Old Containers
-------------------------------------------------------------------

docker-compose down

-------------------------------------------------------------------
STEP 5: Remove Old Containers (Clean Start)
-------------------------------------------------------------------

docker rm -f internaldevelopersplatform-frontend-1 internaldevelopersplatform-backend-1 2>/dev/null || true

-------------------------------------------------------------------
STEP 6: Build New Images
-------------------------------------------------------------------

docker-compose build --no-cache

# This will take 3-5 minutes. Wait for it to complete.

-------------------------------------------------------------------
STEP 7: Start All Services
-------------------------------------------------------------------

docker-compose up -d

-------------------------------------------------------------------
STEP 8: Wait for Services to Start
-------------------------------------------------------------------

sleep 10

-------------------------------------------------------------------
STEP 9: Check Container Status
-------------------------------------------------------------------

docker-compose ps

# You should see:
# - internaldevelopersplatform-backend-1     Up
# - internaldevelopersplatform-frontend-1    Up
# - internaldevelopersplatform-dynamodb-local-1    Up

-------------------------------------------------------------------
STEP 10: Test Backend Health
-------------------------------------------------------------------

curl http://localhost:8100/api/v1/health

# Should return: {"status":"healthy"}

-------------------------------------------------------------------
STEP 11: Test Backend Modules Endpoint
-------------------------------------------------------------------

curl http://localhost:8100/api/v1/modules

# Should return JSON with 5 modules

-------------------------------------------------------------------
STEP 12: Open Firewall Ports
-------------------------------------------------------------------

sudo ufw allow 8100/tcp
sudo ufw allow 3200/tcp
sudo ufw reload

-------------------------------------------------------------------
STEP 13: Get Your VPS IP Address
-------------------------------------------------------------------

hostname -I | awk '{print $1}'

# Note this IP address

-------------------------------------------------------------------
STEP 14: Access from Your Browser
-------------------------------------------------------------------

Open these URLs in your browser (replace YOUR_VPS_IP):

Frontend (UI):
http://YOUR_VPS_IP:3200

Backend API Documentation:
http://YOUR_VPS_IP:8100/docs

Health Check:
http://YOUR_VPS_IP:8100/api/v1/health

-------------------------------------------------------------------
OPTIONAL: View Live Logs
-------------------------------------------------------------------

docker-compose logs -f

# Press Ctrl+C to stop viewing logs

-------------------------------------------------------------------
TROUBLESHOOTING
-------------------------------------------------------------------

If containers won't start:
1. docker-compose down
2. docker system prune -f
3. docker-compose build --no-cache
4. docker-compose up -d

If port is already in use:
1. sudo lsof -i :8100
2. sudo kill -9 <PID>
3. docker-compose up -d

If you can't access from browser:
1. Check firewall: sudo ufw status
2. Make sure ports are open: sudo ufw allow 8100/tcp && sudo ufw allow 3200/tcp
3. Check containers are running: docker-compose ps
4. Check logs: docker-compose logs
